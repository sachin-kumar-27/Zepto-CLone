# ⚡ Zepto Clone - 10 Minute Delivery App

> A fully responsive grocery delivery clone with real images, cart, auth and orders.

**🚀 Live Demo:** https://sachin-kumar-27.github.io/Zepto-Clone/

### ✨ Features
- 🔍 Real-time search
- 🗂️ Category filter - Fruits, Vegetables, Cloth, Electronics, Shoes
- 🛒 Cart with quantity
- 👤 Login / Sign Up
- 📦 My Orders + ❌ Cancel Order
- 📱 100% Mobile Responsive (No overflow bug)
- 🖼️ Real HD images

### 🛠️ Tech Stack
HTML5, CSS3, Vanilla JavaScript, LocalStorage, GitHub Pages

### 🚀 How to Run
Just open index.html - No npm needed
